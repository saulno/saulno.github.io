On building software

2025-10-01

Most software today is bloatware, unnecessary and overly complicated.

There is no respect for time, attention, elegance, succinctness. Five services talking to each other to render a string. Changing the string requires updates on three of them. It was never meant to be like that.

Shortsighted devs complain about LLMs making the same mistakes. It simply increased the diarrhea flow rate. I am actually optimistic about AI enabling self containment. This page is an example. It is a text file. View the source and you have seen everything there is to see. There is something fulfilling in that completeness.

Of course the end user doesn't care about that, they only care about same day deliveries.
